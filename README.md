# e-plantShopping

## Paradise Nursery

Paradise Nursery is a plant shopping application where users can browse and purchase a variety of beautiful houseplants.

## Project Description

Paradise Nursery provides a simple and user-friendly online shopping experience for houseplants. Plants are organized into different categories so users can easily browse the available products.

Users can:

- Browse different categories of plants
- View plant names, prices, and images
- Add plants to the shopping cart
- View the number of items in the cart
- Increase or decrease plant quantities
- Remove plants from the cart
- View the total cost of their shopping cart
- Continue shopping
- Use the checkout option

## Technologies Used

- JavaScript
